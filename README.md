## 四、实名认证 (Ablamacja)：绕不开的步骤

　　2025年，波兰对所有手机卡（含预付费！）实行严格**强制实名制**。不实名？卡会被停用！流程核心：

1.  **证件：** 护照是外国游客唯一选择。有效期内的！
2.  **地点/方式：**
    *   **门店购买：** 店员直接帮你录入系统，当场激活。
    *   **超市/自购卡：** 需**自行在线激活**：访问运营商官网激活页面 (如Play: `rejestracja.play.pl`)，填卡号、护照信息、上传护照照片页+本人持护照自拍（背景干净！）。审核通常1-24小时。
3.  **关键细节：**
    *   持护照自拍时，**护照信息页必须清晰可辨**，人脸无遮挡。见过有人因反光被拒，折腾三次！
    *   地址信息：填酒店地址即可。
    *   激活成功会收到短信。没收到？检查垃圾短信，或联系运营商客服。

　　**比喻一下：** 实名认证就像给你的SIM卡办张“通关文牒”，没它，网络大门对你紧闭。

## 五、设备设置：让网络飞起来

　　卡插好了/ eSIM装上了，实名也过了，还上不了网？十有八九是APN没设对！

*   **APN设置 (关键！)：** 大部分新卡能自动配置，但手动检查更稳：
    *   **Orange:** `internet`
    *   **Play:** `internet`
    *   **T-Mobile:** `internet`
    *   (设置路径：手机设置 > 蜂窝网络 > SIM卡 > 蜂窝数据网络 > APN)
*   **频段兼容：** 波兰主流4G频段：**B3 (1800MHz), B7 (2600MHz), B20 (800MHz - 重要室内覆盖)**；5G：**n1, n28, n78**。你的手机支持吗？特别是老旧机型，查查官网参数。B20频段在农村和室内是“信号救星”。
*   **重启：** 设置完APN或实名后，重启手机！简单但有效。

　　**有没有遇到过？** 明明显示满格4G，网速却慢如蜗牛？试试手动切到3G网络，有时反而更流畅（尤其是旧城区）。
